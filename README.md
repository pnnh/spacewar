# 太空大战 (Space War)

这是一个基于 **Phaser 3** 游戏引擎和 **TypeScript** 开发的经典 Web 版太空射击游戏。

## 🚀 技术栈

- **引擎**: [Phaser 3](https://phaser.io/)
- **语言**: [TypeScript](https://www.typescriptlang.org/)
- **构建工具**: [Vite](https://vitejs.dev/)

## 🎮 游戏功能

### 1. 核心玩法
- **全方向移动**: 使用方向键在屏幕内自由穿梭。
- **惯性飞行**: 模拟真实的太空物理环境，具有丝滑的操控感。
- **自动边界限制**: 玩家飞船无法飞出屏幕范围。

### 2. 武器升级系统
通过击杀特定的特殊敌人，玩家可以升级武器：
- **Lv.1**: 初始单发子弹。
- **Lv.2**: 双重平行子弹，覆盖范围更广。
- **Lv.3**: 三重散射子弹，具有极强的压制力。

### 3. 多样化的敌人
- **普通敌人 (红色圆圈)**: 随机生成，垂直向下移动。
- **进攻型敌人 (橙色圆圈)**: 会主动瞄准玩家位置发射拦截子弹。
- **特殊敌人 (金色菱形)**: 击杀后可获得高额积分并升级武器。
- **大型 Boss (紫色巨型机)**: 
    - 随着得分动态增长而出现。
    - 拥有 10 点生命值。
    - 极高的射速和追踪子弹。
    - 击杀后触发全屏震动特效并奖励 500 分。

### 4. 动态挑战机制
- **递增难度**: 随着 Boss 被击败，下一个 Boss 出现的积分阈值会不断提升。
- **Game Over 系统**: 撞击敌人或被敌方子弹击中将导致游戏结束。支持空格键或鼠标点击快速重启。

## 🛠️ 安装与运行

### 环境要求
- [Node.js](https://nodejs.org/) (建议版本 18+)

### 快速开始
1. **安装依赖**:
   ```bash
   npm install
   ```

2. **启动开发服务器**:
   ```bash
   npm run dev
   ```
   启动后访问 `http://localhost:5173` 即可开始游戏。

3. **生产环境构建**:
   ```bash
   npm run build
   ```

## ⌨️ 操控说明

| 按键 | 动作 |
| :--- | :--- |
| **方向键 (↑ ↓ ← →)** | 控制飞船移动 |
| **空格键 (SPACE)** | 发射子弹 / 游戏结束后重新开始 |
| **鼠标点击** | 游戏结束后重新开始 |

## 📝 项目结构

- `src/main.ts`: 游戏核心逻辑，包含场景管理、物理引擎配置、对象池及 AI 逻辑。
- `index.html`: 游戏入口。
- `tsconfig.json`: TypeScript 配置文件。
- `package.json`: 项目依赖及脚本配置。
